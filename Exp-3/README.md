# Experiment 3: Routing in Single Page Applications (SPA)

## Objective
To understand and implement client-side routing in a Single Page Application using React Router.

## Description
This experiment focuses on understanding how routing works in a Single Page Application (SPA). Multiple routes are created to represent different sections of the application such as Profile and Dashboard. Navigation between these sections happens without reloading the page, demonstrating the core concept of SPA routing.

## Routing Concepts Used
- Client-side routing using React Router
- Defining multiple routes for different paths
- Navigation between routes using links
- Default routing and redirection
- Maintaining a single page while switching views

## What This Experiment Demonstrates
- How SPAs manage navigation internally
- How URLs change without full page reloads
- Improved user experience through seamless routing
- Logical separation of application views using routes

## Outcome
By completing this experiment, we gain a clear understanding of routing in Single Page Applications and how React Router enables smooth navigation between different sections of an application.
